# HastaShilpa

HastaShilpa is a handmade crafts marketplace Android application developed using Kotlin and Jetpack Compose.

## Features

- Splash Screen
- Scrollable Product List
- Search Products
- Product Details Screen
- Bottom Navigation
- Favorites Screen
- Explore Screen
- Profile Screen
- Price Calculator

## Technologies Used

- Kotlin
- Jetpack Compose
- Android Studio
- Firebase
